Relations

Reflexive: (a,a) ∈ R for every a ∈ A
Symmetric: (a,b) ∈ R ⇒ (b,a) ∈ R
Transitive: (a,b),(b,c) ∈ R ⇒ (a,c) ∈ R
Equivalence relation = Reflexive + Symmetric + Transitive

Functions

One-one: f(a)=f(b) ⇒ a=b

Bijective = One-one + Onto

Identity: I(x)=x
Inverse exists iff f is bijective
f⁻¹∘f = I and f∘f⁻¹ = I

Kp = Kc(RT)^Δn

pH

pH = -log[H⁺]
pOH = -log[OH⁻]
pH + pOH = 14 at 25°C

Water

Kᵥ = [H⁺][OH⁻] = 1.0×10⁻¹⁴ at 25°C

Mole

n = given mass / molar mass
Number of particles = nNₐ
Nₐ = 6.022×10²³ mol⁻¹

Gas

PV = nRT
R = 8.314 J mol⁻¹ K⁻¹

Density

ρ = mass/volume

Atomic Structure

E = hν = hc/λ
c = νλ
